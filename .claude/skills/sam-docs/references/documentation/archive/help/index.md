# Help

When you have a question about Solace Agent Mesh that the rest of the documentation does not answer, this is where to look first. The two pages below cover the common cases and tell you which channel is the right fit for everything else.

## Pages in This Section

- **FAQ** — Quick answers to the most common product, deployment, and integration questions. Cross-links into the Concepts, Installing, and Building shelves for the longer explanations.
- **Community and Support** — Where to open a support ticket, ask peer-to-peer questions on the Solace Community forum, or reach your Sales Engineer.

For deploy-time failure modes — broker connection refused, LLM provider auth failures, missing environment variables, port conflicts — start at Installing → Troubleshoot. For day-two scenarios on a running system — broker connectivity loss, persistence-layer failures, upgrade rollbacks — start at Administering → Scenario troubleshooting.
