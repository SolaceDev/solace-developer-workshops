# Agent Mesh

Agent Mesh is a purpose-built runtime for agentic systems on a Solace event mesh. It owns the full agent lifecycle: LLM interaction, tool calling, streaming, artifact handling, sessions, workflows, the A2A protocol, and the HTTP gateway.

If you are new here, start at the Overview — it covers what Agent Mesh is, how it is built, and how to pick the right path for your use case. If you already know what you want to do, jump in from the table below.
