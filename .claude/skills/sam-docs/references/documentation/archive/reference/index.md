# Reference

Lookup material, mostly generated from source-of-truth artifacts. Power users come here when they already know what they want and just need the field name or flag.

## Pages in This Section

- **CLI** — Every command's flags (generated from `--help`).
- **Config schema** — Every YAML field with type and default.
- **Environment variables** — Every env var Solace Agent Mesh-Go reads, plus the placeholders that appear in shipped YAML samples; grouped by concern.
- **Glossary** — Domain terms used throughout.
- **Built-in tools** — The first-class built-in tools the runtime registers at startup, with parameters, return shape, and behavioral notes for each.
- **A2A wire format** — Covered conversationally in Concepts → A2A protocol, which carries the wire-level reference content (envelope, topic conventions, user properties, signal taxonomy, task state vocabulary).
