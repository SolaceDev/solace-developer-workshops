# Overview

This section orients new readers before they commit to an install path. It answers three questions:

- **What is Solace Agent Mesh?** — An event-driven runtime for agentic systems: what it is, what problem it solves, and the shape of the system at a glance.
- **Architecture overview** — The three workload classes (GWE, AWE, STR), the broker between them, where state lives, and the deployment shapes that follow.
- **Choosing your path** — A short decision table that matches what you want to do next — try, install, build, operate, or migrate — to the right entry point.

If you already know which path you want, jump straight to Get Started.
