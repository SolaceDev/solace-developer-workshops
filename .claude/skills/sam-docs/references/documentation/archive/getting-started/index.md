# Get Started

This section orients a new reader and offers two on-ramps:

- **Desktop demo** — install the desktop app and chat with the bundled assistant in 5 minutes.
- **CLI scaffold** — author a project directory, wire an LLM provider, and run your own configured agent locally.

## Pages in This Section

- **Before you begin** — Universal prerequisites: broker decision, LLM API key, network reachability, and where the environment variables live.
- **Try Agent Mesh Desktop** — Install the desktop bundle and chat with the bundled assistant end-to-end.
- **Build your first project** — Author `configs/my-agent.yaml` and `configs/my-gateway.yaml`, run `sam-enterprise run --embedded`, and send a task to your own agent.
- **Next steps** — Pointers into Building, Concepts, Deploy options, Administering, and Migration.
