# Installing and Configuring

This section covers everything from a first install to a running, monitored deployment. Use it whether you're spinning up a desktop preview, running locally from the CLI, or rolling out a Kubernetes deployment with SSO, RBAC, and Helm.

## Pages in This Section

- **Install** — Install the runtime (binary tarball, Docker, desktop bundle, Kubernetes).
- **Configure** — Wire up LLM providers, artifact storage, session storage, broker, MCP servers, RBAC, SSO, and secrets via YAML.
- **Deploy options** — Choose where to run: desktop, CLI, Docker, or Kubernetes (Helm).
- **Compute resources** — CPU and memory requests/limits, node sizing, the bundled-broker cost, and how heavy agents drive infrastructure cost.
- **Monitor** — Deploy-time observability setup: metrics scraping, log aggregation, health endpoints.
- **Airgap** — Offline and disconnected environments.
- **Troubleshoot** — Common deploy-time failure modes and how to diagnose them.
- **What can you build?** — After install, where to go next.

Day-two operations — observability thresholds, runbooks, secret rotation, upgrades, scenario-based troubleshooting — live in Administering.
