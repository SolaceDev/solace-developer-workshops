# Kubernetes

Deploy Solace Agent Mesh on Kubernetes using the Helm chart. Choose the guide that matches your scenario.

- **`link to "Kubernetes Quick Start"` ** — Evaluation and POC deployments with embedded broker, Postgres, and storage. Up and running in minutes, no external dependencies required. Not for production.
- **`link to "Installing Kubernetes for Production"` ** — Full production deployment with external broker, managed databases, object storage, OIDC authentication, TLS, and RBAC.
- **`link to "Installing in an Air-Gapped Environment"` ** — Kubernetes deployments in disconnected environments: obtaining the delivery package, loading images into a private registry, and deploying without internet access.
- **`link to "Migrating the Helm Chart"` ** — Upgrading from a previous Helm chart version.
