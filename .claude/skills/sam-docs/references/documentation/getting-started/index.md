# Getting Started with Agent Mesh

Agent Mesh is an agent development and runtime platform. It helps you build, test, deploy, monitor, and improve your agents and agent workflows. It hosts the agents you build, runs the tools they call, and coordinates everything over an event broker—with sessions, artifacts, authentication, and observability built in. To learn more, see [What Is Agent Mesh?](./what-is-sam.md)
