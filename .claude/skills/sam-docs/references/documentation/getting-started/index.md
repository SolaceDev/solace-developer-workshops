# Getting Started with Solace Agent Mesh

Solace Agent Mesh is an event-driven runtime for agentic systems. It hosts the agents you build, runs the tools they call, and coordinates everything over an event broker—with sessions, artifacts, authentication, and observability built in. To learn more, see [What Is Solace Agent Mesh?](./what-is-sam.md)
