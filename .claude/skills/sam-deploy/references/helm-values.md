# Helm Values Reference

These are the load-bearing keys you actually set, organized by capability with corrected go-only 2.x chart defaults; the full schema and every default live in the **Helm Values Reference** doc and in the `values.yaml` inside the downloaded chart bundle — read those for anything not named here.

| Concern | Keys | Notes |
|---|---|---|
| Images & registry | `global.imageRegistry` (default `gcr.io/gcp-maas-prod`); `global.imagePullKey` **or** `global.imagePullSecrets`; `samDeployment.gwe.image.*`, `samDeployment.awe.image.*`, `samDeployment.str.image.*` | `imagePullKey` is applied with `--set-file` and creates a `kubernetes.io/dockerconfigjson` Secret; `imagePullSecrets` is a list of existing secret names. The two are **mutually exclusive**. GWE repo is `solace-agent-mesh`; AWE inherits GWE; **STR is `solace-agent-mesh-str` and must NOT inherit GWE** — it carries both the Go and Python tool runtimes. |
| Broker | `global.broker.embedded` (default `true`); `broker.url`, `broker.vpn`, `broker.clientUsername`, `broker.password` | `embedded: true` runs the bundled embedded broker — the **single heaviest component** (≥ 2480 MiB). Set `false` for an external broker and fill the `broker.*` connection fields — `broker.url` is `tcps://...:55443` or `wss://...:443`. Sizing tracks which heavy components are enabled, not a flat number: full quickstart needs ~16 GiB, but external broker + bundled persistence is workable on ~8 GiB (see helm-quickstart.md). |
| Persistence | `global.persistence.enabled` (default `true`); `global.persistence.namespaceId` (default `solace-agent-mesh`); `dataStores.database.*`; `dataStores.objectStorage.type`; `dataStores.objectStorage.workloadIdentity.enabled`; `dataStores.s3.*` / `dataStores.azure.*` / `dataStores.gcs.*` | `enabled: true` bundles PostgreSQL + object storage. **`namespaceId` is triple-duty: it scopes the DB/users, is the broker topic prefix** (sets the `NAMESPACE` env var)**, and is the object-storage (S3) bucket name.** Keep it to lowercase letters, digits, dots, and hyphens (no underscores) — S3 bucket naming rules reject underscores, so a value like `greg_test` works for the DB and topics but breaks bundled object storage: the `s3-init` container logs `bucket name can only contain lower case characters, numbers, dots, and hyphens` yet still reports success and exits 0, then GWE fails its startup probe with `HeadBucket 404` / `PutObject 500`. Mirror the hyphenated default `solace-agent-mesh`. On a shared broker (e.g. Solace Cloud) the default collides on topics with any other default install — set a value unique among everyone on that broker. Changing it later re-prefixes topics **and** points SAM at fresh, empty databases. For external stores set `enabled: false`: `dataStores.database.*` = host, port `5432`, adminUsername, adminPassword, applicationPassword, supabaseTenantId; `dataStores.objectStorage.type` is `s3`/`azure`/`gcs` with the matching per-provider block. |
| LLM | `llmService.llmServiceEndpoint`, `llmService.llmServiceApiKey`; `llmService.planningModel`, `generalModel`, `reportModel`, `imageModel`, `transcriptionModel` | The model alias keys are seeds and may be left empty — operators add models in the Console later. |
| Tool API keys | `toolApiKeys.*` (e.g. `anthropic`, `gemini`, `google`, `googleSearchApiKey`, `googleCseId`) | Empty values are omitted from the rendered Secret. |
| Auth (OIDC/RBAC) | `sam.authorization.enabled` (default `false`); `sam.oauthProvider.oidc.issuer` / `clientId` / `clientSecret`; `sam.dnsName`; `sam.sessionSecretKey`; `sam.authenticationRbac.users[]`, `sam.authenticationRbac.idpClaims.*`, `sam.authenticationRbac.customRoles`, `sam.authenticationRbac.defaultRoles` (default `["sam_user"]`) | With `authorization.enabled: false` every user is admin. `sam.dnsName` drives the OIDC redirect URI host. `sessionSecretKey` is auto-generated and stable if left empty. `idpClaims.*` = enabled, oidcProvider, claimKey (default `groups`), mappings. Built-in roles `sam_admin` / `sam_user` are present unless suppressed with `disableBuiltinRoles`. |
| Networking | `service.type` (default `ClusterIP`); `ingress.enabled`, `ingress.className` (`nginx`/`alb`/`traefik`/`gce`), `ingress.host` (default `""`), `ingress.autoConfigurePaths` (default `true`), `ingress.tls`; `sam.dnsName`; `sam.cors.allowedOriginRegex` | Set `ingress.host` to the external hostname (usually the same value as `sam.dnsName`) — it defaults to empty. Leave `autoConfigurePaths` on. `cors.allowedOriginRegex` defaults to localhost-only — set your real origins in production. |
| Environment variables | `extraSecretEnvironmentVars` (list); `environmentVariables` | `extraSecretEnvironmentVars` sources env vars from existing Kubernetes Secrets — use this for secrets. `environmentVariables` renders to a ConfigMap in **plaintext** — non-secret only; put `HTTP_PROXY` / `HTTPS_PROXY` here for proxied / air-gapped egress. |
| Deployment / rollout | `samDeployment.rollout.strategy` (default `RollingUpdate`); `samDeployment.serviceAccount.name` / `.annotations`; `samDeployment.customCA.enabled` / `.configMapName` (default `truststore`); `samDeployment.resources.*` | Set `strategy: Recreate` to avoid overlap — each pod is a single replica and GWE hosts the in-process platform. `serviceAccount` annotations carry workload identity. `resources.*` is quickstart-sized by default; raise for real load. |
| Validations | `validations.clusterResourceChecks` (default `true`) | Template-time checks that referenced Secrets/ConfigMaps/StorageClass/IngressClass exist; needs `get` RBAC. Disable to skip. |
| Pre-flight | `samDoctor.enabled` (default `true`), `samDoctor.failOnError` (default `true`), `samDoctor.timeoutSeconds` (default `180`), `samDoctor.tlsDnsName` (defaults to `sam.dnsName`) | Failed runs are retained — read their logs. |

For the full schema and every default, see the **Helm Values Reference** doc, or read `values.yaml` in the downloaded chart bundle.
